# ADR 0008: Two-layer estate with governed application catalogs

**Status:** Accepted

RES separates the coherent enterprise application from the semantic behavior corpus. Machine-readable component, workflow, capability-allocation and bidirectional trace catalogs join the layers without making every semantic edge a production feature. Each capability receives a business-integrated, operations-integrated or semantic-edge placement. Validators reject broken references, unallocated taxonomy entries and workflow capabilities without a semantic family. The taxonomy remains explicitly partial, so a gap-free seed report is not a completeness claim.
