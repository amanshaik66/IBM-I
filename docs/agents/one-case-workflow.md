# One semantic case per agent

A task owner assigns exactly one semantic ID and creates a branch plus worktree. The contract allow-list is enforceable review scope; registry schemas, existing semantics, global architecture and unrelated cases are forbidden unless a separate architecture task approves them. Claim ownership before editing and declare prerequisites.

Deliver source/fixtures, setup and idempotent cleanup, observable expectations, concise documentation references, tests, and the updated record. Run local gates. Request independent review and merge through CI. Agents must use `requires_investigation` for uncertainty and must never infer IBM i verification from source inspection or mocks. LPAR execution is centrally scheduled with a unique library lease and resource limits.

Implementation-only contracts must forbid expected-semantics changes. If observed IBM i behavior disagrees with an expectation, preserve the failed evidence and open a separate semantic-definition review task. That task increments the semantic-definition version, records rationale and authoritative provenance, and requires verifier plus independent reviewer approval. Implementers cannot self-approve verification.
